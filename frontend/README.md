# Frontend — Détecteur de risque financier

Application Next.js 16 (App Router, Tailwind v4, React 19) du projet :
recherche d'entreprise, fiche de risque par CIK (niveaux + signaux détaillés,
graphique d'évolution, dépôt source), pages publiques indexées
(sitemap/robots).

Commandes et mise en route : voir le [README à la racine](../README.md).

```bash
pnpm install
pnpm dev      # lit NEXT_PUBLIC_API_URL (défaut http://localhost:8011)
```
